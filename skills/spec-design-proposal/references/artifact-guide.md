# アーティファクトの作り方

## ページ構成

`assets/proposal-template.html` はこの順に並んでいる。読み手が上から読むだけで「何を決めるのか → 何が決まっているのか → どの案が良いのか」がわかる順序にしてある。

1. **ヘッダー**: タイトル、決めたいこと (1〜2文)、推奨案 (1文)、日付
2. **背景と業務フロー**: アクター、きっかけ、ステップ。フロー図はシンプルな横並びのステップで描く
3. **ユースケース**: アクターごとの「〜したい」。主要 / 少数だが重い を分ける
4. **前提条件**: 4種類 (仕様上の制約、技術的制約、スコープ外、決定済みの方針) と出典
5. **固定した判断**: 固定した変数と理由
6. **検討の主軸**: 案の違いを生む軸と、それぞれの案の立ち位置
7. **案A〜C**: 各案に、一言の説明、業務フローの流れ、モック、(必要なら) プロトタイプ、強い/弱いユースケース、実装コストとリスク、未解決の論点
8. **比較表**: 主軸と評価観点 × 案
9. **推奨と理由**: 推奨案、重視した前提とユースケース、他の案を選ぶべき状況
10. **次に決めること**: 利用者や関係者に判断してほしい論点

ヒアリングで「わからない」まま残ったものは、該当箇所に「未確認」と明示する。

## 静的モックとプロトタイプの使い分け

| 違いが出るところ | 使うもの |
|---|---|
| 情報の配置、一覧性、画面の密度 | 静的モック |
| 状態ごとの見え方 (空、エラー、権限なし) | 静的モックを状態ぶん並べる |
| 操作の手数、画面遷移、ダイアログの出方 | プロトタイプ |
| 入力しながらの反応 (バリデーション、絞り込み、プレビュー) | プロトタイプ |
| 一括操作、並べ替え、選択状態の変化 | プロトタイプ |

迷ったら「静止画を見て、読み手が操作の手数を正しく想像できるか」で判断する。できないならプロトタイプにする。全案にプロトタイプを付ける必要はないが、操作が論点なら比較対象の案すべてに付ける (片方だけ触れると公平に比べられない)。

## モックの作り方

- モックは HTML/CSS で描く。`assets/smarthr-ui-like.css` のクラスを `.sui-frame` の内側で使う
- 画像ファイル (PNG) が別途必要なときは、Playwright でモックの要素をスクリーンショットする (deviceScaleFactor: 2)
- データは業務に即した具体的な値を入れる (「テキスト」「項目1」ではなく「2026年度上期 評価」「山田 太郎」など)。ただし実在の個人名・顧客名は使わない
- 案同士で同じデータを使う。データが違うと、案の違いなのかデータの違いなのかがわからなくなる
- 各モックの左上に「モック」ラベルを付ける (テンプレートの `.mock-label`)

## プロトタイプの作り方

- 1案につき1つの `.sui-frame[data-proto]` に閉じ込める。素の JavaScript で書き、状態はその要素の中だけで持つ
- 外部ライブラリは原則使わない。React などが必要なら cdnjs から、2週間以上前に公開されたバージョンを固定して読み込む
- 主要ユースケースを最後まで操作できるところまで作る。見せたい論点に関係しない部分 (他のメニュー、設定画面など) は作らない
- 「最初に戻す」ボタンを付ける
- 保存・送信は実際には行わない。操作結果は画面内の状態変化と、NotificationBar 風の表示で返す
- localStorage などに状態を残さない (検討資料なので、開くたびに同じ初期状態から始まるほうがよい)

## 公開の手順

1. テンプレートをスクラッチパッド (なければ作業ディレクトリ外の一時ディレクトリ) にコピーして中身を埋める
2. `scripts/inline_css.py <html>` で `<!-- SUI_CSS -->` を `assets/smarthr-ui-like.css` の中身に置き換え、1ファイルにする
3. Playwright で開き、ライト/ダーク両方と幅 375px で崩れがないか、プロトタイプが最後まで操作できるかを確認する
4. `artifact-design` スキルを読み込んでから、Artifact ツールで公開する。アイコンは `layout` など一般名詞にする
5. 修正時は同じファイルパスで再公開し、URL を変えない

Artifact ツールが使えない環境では、HTML ファイルを作業ディレクトリに保存して、そのパスを伝える。
